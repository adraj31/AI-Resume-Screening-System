About the Project

A final year B.Tech project that brings AI to the recruitment process

Project Overview

The AI Resume Screening System is a final year B.Tech Computer Science project that automates the initial screening of candidate resumes using Machine Learning and Natural Language Processing techniques.

In traditional hiring, recruiters spend an average of 6-8 seconds scanning each resume. With hundreds of applications per position, this process is time-consuming and prone to human bias. Our system addresses this by providing instant, consistent, and data-driven resume screening.

The system predicts the most suitable job category for a given resume and optionally computes a match score against a specific job description using cosine similarity.

Our Methodology

A structured approach to building an accurate resume classifier

01

Data Collection

We used the Kaggle Resume Dataset containing 962 resumes across 25+ job categories including Data Science, Web Development, HR, and more.

02

Text Preprocessing

Resumes undergo cleaning to remove URLs, hashtags, mentions, special characters, and stopwords using NLTK for consistent text normalization.

03

Feature Extraction

TF-IDF (Term Frequency-Inverse Document Frequency) vectorization converts cleaned text into numerical features with max_features=1500.

04

Model Training

Three classifiers were compared: LinearSVC (85.3%), KNN (79.4%), and Random Forest (73.5%). LinearSVC was selected as the best performer.

05

JD Matching

Cosine similarity between TF-IDF vectors of the resume and job description provides a 0-100% match score with calibrated thresholds.

06

Web Deployment

The trained model is serialized using pickle and served through a Flask web application with an intuitive drag-and-drop interface.
